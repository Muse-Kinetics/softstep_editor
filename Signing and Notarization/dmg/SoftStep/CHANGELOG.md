#### SoftStep Editor and Firmware Changelog

### Editor 2.1.0, Firmware 1.0.0 (2021-03-14)
- New Features/Changes:
	- Overhauled MIDI backend using RtMidi, now builds/runs on modern operating systems.
	- Editor will install a new bootloader into firmware before upgrading to 1.0.0. This change is permanent and protects firmware from getting corrupted.
	- Hosted mode now responds to program changes sent to SoftStep Share port on channel 16.
- Bug Fixes:
	- Replaced old low-res UI images with vector fonts.
