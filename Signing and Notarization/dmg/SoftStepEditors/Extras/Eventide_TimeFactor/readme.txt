EvenTide TimeFactor instructions:


In this folder is everything you need to get your Eventide TimeFactor up and running with the SoftStep.  Included are 2 .syx files, one with just the system settings and one that will dump everything.  If you've made your own presets on the Eventide I recommend using just the system settings file and also making a backup of your current settings before dumping ours onto it.  Also included is the users manual for the Eventide.  It should tell you how to dump and restore .syx files.  

If you're on a Mac you can use this free application called Sysex Librarian which you can download here:

http://www.snoize.com/SysExLibrarian/

If you are on a Windows computer you can use MIDI Ox, also a free application you can download from here:

http://www.midiox.com/


The EvenTide - TimeFactor scene is in the Standalone Scene list of the SoftStep Editor application.  Put this scene in your setlist along with the program change scene.  Then hit the download button and the 2 scenes should be sent down to the SoftStep.  Now you can use the SoftStep with the Eventide after you put the .syx file on it.

Also in this folder is a little .pdf file that shows you what the Program Change and TimeFactor scene are supposed to do.

Enjoy!
